# Курсовая работа - Проект 3: Поиск вакансий с подключением БД (Работа с базой данных и API hh.ru) 
## Цель проекта

Реализовать программу, которая получает данные о компаниях и их вакансиях с сайта hh.ru 
через публичный API, сохраняет эти данные в базу данных PostgreSQL
и предоставляет инструменты для анализа и просмотра информации.

##  Задачи проекта

### В рамках проекта необходимо:

- Получить данные о работодателях и их вакансиях с сайта hh.ru с помощью API.

- Выбрать не менее 10 компаний для загрузки данных.

- Спроектировать таблицы в базе данных PostgreSQL для хранения информации:

  1. companies — таблица работодателей

  2. vacancies — таблица вакансий (связана с компаниями по company_id)

- Заполнить таблицы данными, полученными через API.

- Создать класс DBManager для удобной работы с БД и реализации аналитических запросов.

- Реализовать интерактивное меню для взаимодействия с пользователем.

## Установка и настройка
1. Установите зависимости проекта
```
poetry install
```
или, если вы используете pip:
```
pip install -r requirements.txt
```
2. Настройте базу данных PostgreSQL
```
Убедитесь, что у вас установлен и запущен сервер PostgreSQL.
```
3. Создайте файл config.py
```
Файл не добавляется в репозиторий, т.к. содержит персональные данные.
Создайте его вручную в папке src/, используя шаблон config_example.py:
```
```
DB_CONFIG = {
    "dbname": "hh_project_db",   # название базы данных
    "user": "postgres",          # имя пользователя
    "password": "your_password", # пароль
    "host": "localhost",         # адрес сервера
    "port": "5432"               # порт PostgreSQL
}
```

## Запуск проекта

Запустите проект командой:
```
python src/main.py
```

Программа создаст базу данных (если она отсутствует),
создаст необходимые таблицы и предложит загрузить данные с сайта hh.ru.

## Возможности программы

После запуска доступно интерактивное меню:
```
МЕНЮ УПРАВЛЕНИЯ
1. Список компаний и количество вакансий
2. Все вакансии
3. Средняя зарплата по вакансиям
4. Вакансии с зарплатой выше средней
5. Поиск вакансий по ключевому слову
0. Выход
```

1. Список компаний и количество вакансий
```
Выводит таблицу всех компаний и число опубликованных вакансий.
```
2. Все вакансии
```
Отображает все вакансии с указанием:
- компании,
- названия вакансии,
- диапазона зарплаты (в удобном формате: 120 000–150 000 RUR),
- ссылки на вакансию.
```
3. Средняя зарплата
```
Показывает среднее значение зарплаты по всем вакансиям.
```
4. Вакансии с зарплатой выше средней
```
Выводит вакансии, чьи зарплаты превышают среднюю.
```
5. Поиск вакансий по ключевому слову
```
Ищет вакансии, содержащие введённое слово (по умолчанию "Python").
```
## Класс DBManager

Класс реализует методы для аналитики данных:

Метод                                    | Описание                                                       
-----------------------------------------|---------------------------------------------------------------
 *get_companies_and_vacancies_count()*   | Возвращает список компаний и количество вакансий у каждой     
 *get_all_vacancies()*                   | Возвращает все вакансии с указанием компании, зарплаты и ссылки
*get_avg_salary()*                       | Вычисляет среднюю зарплату по всем вакансиям
*get_vacancies_with_higher_salary()*     | Возвращает вакансии с зарплатой выше средней
*get_vacancies_with_keyword(keyword)*    | Возвращает вакансии, содержащие ключевое слово в названии


## Лог ошибок

В процессе загрузки данных создаётся файл errors.log.
Он содержит информацию о возможных ошибках при работе с API hh.ru.

Если ошибок не было, в конце файла появится запись:
```
Ошибок не обнаружено
```
